# Elliott-byte Tap

## How do I install these formulae?

`brew install elliott-byte/tap/<formula>`

Or `brew tap elliott-byte/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "elliott-byte/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
